# 實驗設計類型說明

> 依據：Campbell & Stanley (1963); Cook & Campbell (1979)

## 真實驗設計（True Experimental Designs）

### 1. 前後測控制組設計（最標準）
```
R  O₁  X  O₂    ← 實驗組（R = Random Assignment）
R  O₁     O₂    ← 控制組
```
**優點**：內在效度最高，可以確立因果關係
**缺點**：成本高，學校場域難以實施

### 2. 後測控制組設計
```
R     X  O₁    ← 實驗組
R        O₁    ← 控制組
```
**優點**：避免前測效應（測試效應）
**缺點**：無法確認初始等同性

### 3. 所羅門四組設計
```
R  O₁  X  O₂    ← 組1
R  O₁     O₂    ← 組2
R     X  O₂     ← 組3
R        O₂     ← 組4
```
**優點**：可測前測效應的影響大小
**缺點**：需要四倍樣本

---

## 準實驗設計（Quasi-Experimental Designs）

### 4. 不等控制組前後測設計（台灣學校研究最常見）
```
O₁  X  O₂    ← 實驗組（現有班級）
O₁     O₂    ← 控制組（現有班級）
```
**注意**：需用 ANCOVA 控制前測差異，誠實說明推論限制

### 5. 單組前後測設計（弱設計，不建議）
```
O₁  X  O₂
```
**問題**：無法排除成熟效應、歷史效應

---

## 組內設計（Within-Subject Designs）

### 6. 交叉設計（Crossover / Counterbalanced）
```
組A：介入A → 沖洗期 → 介入B
組B：介入B → 沖洗期 → 介入A
```
**優點**：每位受試者都嘗試兩種條件，減少個體差異
**適用**：比較兩種教學法、評估學習效果

---

## 效果量（Effect Size）參考表

| Cohen's d | 效果大小 | 解釋 |
|-----------|---------|------|
| 0.20 | 小效果 | 細微但可能有意義 |
| 0.50 | 中效果 | 實務上可觀察到 |
| 0.80 | 大效果 | 明顯可見 |

**如何決定預期效果量**：
1. 先查先行研究的效果量（最可靠）
2. 保守使用中效果量（d = .50）
3. 考慮實務意義（多大效果才值得介入？）
