# Cohen's Kappa 計算完整指南

> 依據：Cohen, J. (1960). A coefficient of agreement for nominal scales.
> Educational and Psychological Measurement, 20(1), 37-46.

## 什麼是 Kappa？

Cohen's Kappa（κ）是衡量兩位評估者（編碼者）在名義量尺上一致程度的統計量，
**已排除隨機一致的可能性**（這是它優於簡單百分比的原因）。

---

## 計算步驟（以二分類為例）

### 情境：兩位編碼者各自對 50 篇新聞進行「是否含衝突框架」的判斷

**步驟 1：建立混淆矩陣**

```
               編碼者 B
               「是」  「否」  行合計
編碼者A  「是」   20      3       23
         「否」    2     25       27
         列合計   22     28       50
```

**步驟 2：計算 Po（實際一致率）**
```
Po = (a + d) / N = (20 + 25) / 50 = 45/50 = .90
```

**步驟 3：計算 Pe（機率期望一致率）**
```
Pe = [(行合計_是/N) × (列合計_是/N)] + [(行合計_否/N) × (列合計_否/N)]
   = [(23/50) × (22/50)] + [(27/50) × (28/50)]
   = [.46 × .44] + [.54 × .56]
   = .2024 + .3024
   = .5048
```

**步驟 4：計算 κ**
```
κ = (Po - Pe) / (1 - Pe)
  = (.90 - .5048) / (1 - .5048)
  = .3952 / .4952
  = .798 ≈ .80
```

**詮釋**：κ = .80，屬於「高度一致」，符合傳播研究 ≥ .80 的標準。

---

## 多分類 Kappa

當有 3 個以上類別時（如：正面/中立/負面），步驟相同，
只是混淆矩陣擴展為 3×3（或更大），Pe 的計算需對應所有對角線元素。

**建議使用工具計算**：
- SPSS：Analyze → Descriptive Statistics → Crosstabs → Statistics → Kappa
- R：`library(psych); cohen.kappa(data_matrix)`
- Python：`from sklearn.metrics import cohen_kappa_score`

---

## Kappa vs. 簡單百分比一致率

| 情況 | 簡單百分比 | Cohen's Kappa |
|------|-----------|---------------|
| 兩類別，隨機猜測 | .50 | ≈ .00 |
| 高度傾斜分佈（一類佔 90%） | .81（虛高） | .00（正確） |
| 真正高一致性 | .90 | .80 |

**結論**：簡單百分比在類別分佈不均時會嚴重虛高，Kappa 才是可信的信度指標。

---

## 提升 Kappa 的策略

當 κ 偏低時（< .70）：

1. **修訂定義**：類別邊界不清楚，需加入更多包含/排除標準
2. **增加範例**：在編碼手冊中加入更多正/負面範例
3. **訓練編碼者**：先一起練習編碼，討論分歧案例
4. **聚合類別**：若某兩類常被混淆，考慮合併
5. **排除邊界案例**：記錄並說明不確定案例的處理原則
