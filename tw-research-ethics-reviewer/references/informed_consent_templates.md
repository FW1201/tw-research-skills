# 知情同意書範本庫

> 依據：台灣《人體研究法》（民國 100 年制定，歷次修正）
> 及《個人資料保護法》相關規定

---

## 版本一：一般成人問卷研究（標準版）

```
研究參與知情同意書

研究題目：[研究完整題目]
主持研究者：[姓名]，[職稱]
服務機構：[機構全名]，[系所]
聯絡電子郵件：[email]
IRB 核准編號：[編號]（若已取得）

═══════════════════════════════════════════════

親愛的參與者，您好：

感謝您閱讀本份說明。我們正在進行一項關於「[研究主題簡述]」
的學術研究，誠摯邀請您參與。

【研究目的】
本研究旨在[研究目的，1-2 句]。

【研究方式】
您將被邀請填寫一份問卷，預計需要 [X] 分鐘。
問卷內容包括：[問卷主要內容簡述]。

【參與風險】
本研究預期風險極低，問卷內容涉及[說明]，
若任何問題讓您感到不適，您可以隨時停止作答。

【個人資料保護】
• 所有資料將以代號取代個人識別資訊
• 研究資料僅供學術研究使用，不對外公開個人資料
• 資料加密保存，研究結束後 [X] 年銷毀

【自願參與】
您的參與完全出於自願，您可以在任何時候、
不需要任何理由退出本研究，且不會受到任何不利影響。

【研究結果】
研究結果將以學術論文或報告形式發表，
所有資料均以匿名或彙總方式呈現，無法辨識個人。

【聯絡窗口】
如有任何問題，請聯絡：
研究者：[姓名] ([email])
機構 IRB 辦公室：[聯絡方式]（若有）

═══════════════════════════════════════════════

同意書：

□ 我已閱讀以上說明，了解本研究的目的、方式與個資保護措施。
  我自願參與本研究，同意研究者使用我提供的資料進行學術研究。

參與者簽名：________________  日期：____________
                                （或以開始填寫問卷視為同意）

研究者簽名：________________  日期：____________
```

## 版本二：訪談研究（含錄音授權）

```
研究參與知情同意書（訪談版）

[基本資訊同上...]

【研究方式】
您將接受一對一深度訪談，預計 [X] 分鐘。
訪談將進行錄音，以利後續逐字稿轉錄分析。

【錄音授權】
□ 我同意研究者對本次訪談進行錄音
□ 我不同意錄音（研究者將以手寫筆記代替）

【個人資料保護】
• 錄音檔案加密保存，研究結束後銷毀
• 逐字稿以代號取代個人資訊
• 研究報告中若引用訪談內容，將徵得您的確認

[其餘聲明同標準版...]

同意書：
參與者簽名：________________  日期：____________
研究者簽名：________________  日期：____________
```

## 版本三：未成年人研究（需親權人同意）

```
未成年研究參與同意書

[研究基本資訊...]

親愛的家長/監護人，您好：

本研究邀請 [X]-[X] 歲學生參與...

【研究目的與方式】[同上...]

【親權人同意】
□ 我同意我的子女/受監護人 ___________（填寫姓名）
  參與本研究

□ 我不同意其參與本研究

親權人簽名：________________
與研究對象關係：________________
日期：________________________

【學生本人同意（12 歲以上）】
□ 我同意參與本研究

學生簽名：________________  日期：____________
```

## 電子問卷同意聲明（替代書面同意書）

```
若採用線上匿名問卷，可使用以下開頭聲明替代書面同意書：

═══════════════════════════════════════════════
研究說明與參與同意

感謝您參與本研究問卷。在開始填答之前，請閱讀以下說明：

研究目的：[1-2 句]
問卷時間：約 [X] 分鐘
資料使用：僅供學術研究，匿名處理，不會公開個人資訊
自願原則：您可以隨時停止填答，不會有任何影響

若您願意參與，請繼續填答問卷（即視為同意參與）。
若您不願意參與，請關閉本頁面。

如有疑問，請聯絡：[研究者 email]
═══════════════════════════════════════════════
```
