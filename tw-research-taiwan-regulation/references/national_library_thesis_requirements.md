# 國家圖書館學位論文繳交規範

> 資料來源：國家圖書館全國博碩士論文資訊網（ETD）
> 網址：https://etd.ncl.edu.tw/
> 最後確認日期：2024 年
> ⚠️ 規定可能更新，繳交前請至官網確認

---

## 基本規定

### 法規依據
- 《學位授予法》（教育部）
- 《國家圖書館學位論文提送辦法》
- 《學位論文電子檔繳交辦法》（各大學）

### 繳交義務
1. 取得學位後，必須將論文電子檔送繳國家圖書館
2. 繳交期限：一般為口試通過後 [X] 個月內（依校規）
3. 繳交方式：至 https://etd.ncl.edu.tw/ 線上申請

---

## 電子檔規格要求

### 檔案格式
| 格式 | 說明 | 建議 |
|------|------|------|
| **PDF/A** | ISO 長期保存標準 | ✅ 最佳選擇 |
| **PDF** | 一般格式 | ✅ 可接受 |
| Word/其他 | 非電子書格式 | ❌ 不接受 |

### 技術規格
- **字型內嵌**：必須將所有字型內嵌（Embed Fonts）
  - Word → 另存為 PDF → 選項 → 勾選「在檔案中內嵌字型」
  - 防止在其他電腦上字型消失或亂碼
- **檔案大小**：一般 < 50MB（含圖片論文可例外）
- **檔案加密**：不可設定密碼保護（影響系統讀取）
- **頁碼連續**：電子版必須頁碼連續（封面到最後一頁）

### 書籤設定（強烈建議）
在 PDF 中設定書籤，對應論文章節：
```
▶ 封面
▶ 口試委員審定書
▶ 謝誌
▶ 中文摘要
▶ 英文摘要
▶ 目次
▶ 圖目次
▶ 表目次
▶ 第一章 緒論
  ▶ 第一節 研究背景
  ▶ ...
▶ 參考文獻
▶ 附錄
```

## 論文後設資料（Metadata）填寫

繳交時需填寫以下欄位：

| 欄位 | 說明 | 必填 |
|------|------|------|
| 論文題目（中文） | 完整題目 | ✅ |
| 論文題目（英文） | 完整英文題目 | ✅ |
| 研究生姓名 | 中英文 | ✅ |
| 指導教授 | 中英文姓名 | ✅ |
| 學校 | 學校全名 | ✅ |
| 系所 | 系所全名 | ✅ |
| 學位 | 碩士/博士 | ✅ |
| 畢業學年度 | 民國學年度 | ✅ |
| 論文摘要（中文） | 300-500 字 | ✅ |
| 論文摘要（英文） | 150-300 words | ✅ |
| 關鍵詞（中文） | 3-8 個 | ✅ |
| 關鍵詞（英文） | 3-8 個 | ✅ |
| 語言別 | 中文/英文/其他 | ✅ |
| 公開授權 | 立即/一年後/不公開 | ✅ |

## 公開授權選擇

| 選項 | 說明 | 建議情境 |
|------|------|--------|
| **立即公開** | 繳交後即可全文下載 | 一般學術研究（推薦） |
| **一年後公開** | 保護未發表成果 | 即將投稿期刊 |
| **不公開（限閱）** | 僅校內可閱覽 | 含商業機密/受保護資料 |

## 繳交流程

```
1. 取得口試委員審定書（正本）
   ↓
2. 完成論文最終修訂（指導教授確認）
   ↓
3. 至學校圖書館繳交（印刷本 + 電子檔）
   - 取得學校收據
   ↓
4. 至 https://etd.ncl.edu.tw/ 申請帳號
   ↓
5. 線上填寫後設資料
   ↓
6. 上傳 PDF 電子檔
   ↓
7. 填寫授權書（線上）
   ↓
8. 等待審核（通常 3-7 工作天）
   ↓
9. 收到確認通知 → 完成
```

## 常見問題

**Q：紙本論文還需要印嗎？**
A：依學校規定。部分學校（師大等）仍要求紙本，
   近年趨勢為電子版為主。

**Q：論文可以更正嗎？**
A：繳交後如需勘誤，需聯繫國圖辦理更正流程。
   建議繳交前仔細確認。

**Q：外籍生也需要繳交嗎？**
A：是的，在台取得學位的外籍生同樣需要送繳。
