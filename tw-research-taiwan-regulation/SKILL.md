# 台灣學位論文規範校對工具 v1.0

## 核心哲學
「**格式合規，是對指導教授和口試委員最基本的尊重。**
口試通過只是開始，繳交格式正確才算完成學位論文。
本工具幫你確認每一個細節，不讓格式問題成為最後的絆腳石。」

> 參考來源：
> - 國家圖書館《學位論文提交須知》
> - 教育部《大專校院學位授予法》（民國 111 年修正）
> - 各大學研究生論文撰寫規範

## Step 3：論文格式規範檢查

### A. 封面頁格式（Cover Page）

```
□ A1. 封面要素完整性
  必要項目（依序排列）：
  
  ① 校徽（位置：中央上方或左上角，依學校規定）
  ② 學校全名（如：國立臺灣師範大學）
  ③ 系所名稱（全名，如：華語文教學系）
  ④ 學位類別（碩士論文 / 博士論文）
  ⑤ 論文題目（中文主標題）
  ⑥ 論文英文題目（English Title）
  ⑦ 研究生姓名（中文 + 英文）
  ⑧ 指導教授姓名（中文 + 英文 + 職稱）
  ⑨ 中華民國 [X] 年 [X] 月（口試通過或繳交月份）
  
  狀態：[ ] ✅ 完整  [ ] ❌ 缺少以下：___

□ A2. 封面字型規格
  標準：新細明體（中文）/ Times New Roman（英文）
  學校名稱：20-24pt 粗體
  論文題目：18-20pt 粗體
  姓名/指導教授：14-16pt
  年份：12-14pt
  狀態：[ ] ✅ 通過  [ ] ❌ 需調整

□ A3. 年份格式
  中文論文：使用民國年（民國 1XX 年 X 月）
  英文論文：使用西元年（[Year], [Month]）
  注意：民國 = 西元 - 1911
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正
```

### B. 書名頁（Title Page）

```
□ B1. 書名頁 vs. 封面
  書名頁通常為第一頁（無頁碼），封面為封皮
  內容與封面相同，但通常加入：
  □ 口試委員名單（依學校規定）
  □ 口試日期
  
  狀態：[ ] ✅ 通過  [ ] ❌ 需補充  [ ] ⚠️ 依學校規定
```

### C. 摘要頁格式

```
□ C1. 中文摘要
  字數：300-500 字（依學校規定）
  關鍵詞：3-8 個（標示「關鍵詞：」）
  
□ C2. 英文摘要（Abstract）
  字數：150-300 words（依學校規定）
  關鍵詞：標示「Keywords:」，3-8 個
  
□ C3. 摘要頁頁碼
  使用羅馬數字（i, ii, iii...）
  前置頁（摘要/目次）使用羅馬數字
  正文開始使用阿拉伯數字（1, 2, 3...）
  
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正
```

### D. 目次格式

```
□ D1. 目次（Table of Contents）
  包含：章節標題 + 頁碼（以 ... 或 --- 連接）
  格式：一致縮排，層級清楚
  
□ D2. 圖目次（List of Figures）
  包含：圖 X. 圖說 + 頁碼
  
□ D3. 表目次（List of Tables）
  包含：表 X. 表說 + 頁碼
  
  狀態：[ ] ✅ 完整  [ ] ❌ 缺少：___
```

### E. 正文格式

```
□ E1. 頁面設定
  紙張：A4（297 × 210 mm）
  邊距：上下各 2.5cm，左右各 2.5cm
  （裝訂邊：左側 3cm，若需裝訂）
  
□ E2. 字型字號
  中文內文：12pt 新細明體 / 標楷體
  英文內文：12pt Times New Roman
  行距：1.5 倍（部分學校要求 double space）
  
□ E3. 章節標題層級
  第一章：居中，20pt 粗體
  第一節：靠左，16pt 粗體
  第一項：靠左，14pt 粗體
  （依學校規定）
  
□ E4. 頁碼位置
  通常：頁面底部中央或右下角
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正
```

### F. 參考書目

```
□ F1. 格式統一
  中文文獻：依 APA 7th 繁體中文規範
  英文文獻：依 APA 7th 英文規範
  
□ F2. 排列方式
  中文文獻：依作者姓氏筆畫排列（或音序）
  英文文獻：依作者姓氏字母順序
  通常：中文文獻在前，英文文獻在後
  
□ F3. 標題
  「參考文獻」或「參考書目」
  （依學校規定，通常置中、粗體）
  
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正
```

## Step 4：國家圖書館繳交規範

```
╔══════════════════════════════════════════════════╗
國家圖書館學位論文繳交要點
（依國家圖書館《學位論文提交須知》）
╠══════════════════════════════════════════════════╣
必要繳交項目：
□ 電子版論文（PDF/A 格式）— 永久保存格式
□ 國圖學位論文授權書（線上填寫）
□ 學校圖書館收據（通常需先繳學校）

電子檔規格：
□ 格式：PDF/A（建議）或 PDF
□ 內嵌字型：是（避免換電腦後字型跑掉）
□ 書籤：設定章節書籤（提升可讀性）
□ 後設資料：填寫標題/作者/摘要

授權方式（三選一）：
□ 立即公開（最支持學術傳播）
□ 一年後公開
□ 不公開（限閱，需特殊原因）
╚══════════════════════════════════════════════════╝
```
