# 論文結構模板庫

> 設計參考：research-writing-skill/Norman-bury（writing-chapters 模組）
> 本庫提供台灣常見論文格式的標準結構模板

---

## 台灣碩士論文五章式（量化實證）

```
第一章 緒論
  1.1 研究背景與動機
  1.2 研究目的
  1.3 研究問題
  1.4 研究假設（量化研究需要）
  1.5 研究範圍與限制
  1.6 名詞界定
  1.7 論文架構

第二章 文獻探討
  2.1 [核心理論 A]
  2.2 [核心理論 B]
  2.3 [先行相關研究]
  2.4 [研究缺口與本研究定位]

第三章 研究方法
  3.1 研究設計（整體設計說明）
  3.2 研究對象與取樣
  3.3 研究工具（問卷/訪談大綱/測驗）
     3.3.1 工具說明
     3.3.2 信效度分析
  3.4 研究程序
  3.5 資料分析方法

第四章 研究結果
  4.1 [對應研究問題一的結果]
  4.2 [對應研究問題二的結果]
  4.3 [對應研究問題三的結果]
  4.4 其他發現（若有）

第五章 結論與建議
  5.1 研究結果摘要
  5.2 研究結果討論
  5.3 學術貢獻
  5.4 實務建議
  5.5 研究限制
  5.6 未來研究方向
  5.7 結語

參考文獻
  中文文獻
  英文文獻

附錄
  附錄一：研究工具
  附錄二：IRB 核准文件
```

## 台灣碩士論文五章式（質性研究）

```
第一章 緒論
  （同量化版）

第二章 文獻探討
  （同量化版，但可加入方法論文獻）

第三章 研究方法
  3.1 研究典範（質性研究哲學）
  3.2 研究設計（訪談/觀察/文件分析）
  3.3 研究場域與研究對象
  3.4 資料收集方法
  3.5 資料分析方法（主題分析/紮根理論等）
  3.6 研究信實度（可信性/可遷移性/可靠性/可確認性）
  3.7 研究倫理

第四章 研究發現與討論（質性研究常將結果與討論合併）
  4.1 [主題一：含發現+詮釋]
  4.2 [主題二：含發現+詮釋]
  4.3 [主題三：含發現+詮釋]

第五章 結論與建議
  （同量化版）
```

## 期刊論文 IMRaD（英文）

```
Title（標題）
Abstract（摘要，150-250 words）
Keywords（關鍵詞，5-8個）

1. Introduction（引言）
   1.1 Background and Motivation
   1.2 Research Gap
   1.3 Research Purpose/Questions
   1.4 Theoretical Contributions

2. Literature Review（可選，部分期刊整合到 Introduction）

3. Methodology
   3.1 Research Design
   3.2 Data/Participants
   3.3 Instruments/Measures
   3.4 Analytical Approach

4. Results
   4.1 [Addressing RQ1]
   4.2 [Addressing RQ2]

5. Discussion
   5.1 Summary of Key Findings
   5.2 Theoretical Implications
   5.3 Practical Implications

6. Conclusion
   6.1 Contributions
   6.2 Limitations
   6.3 Future Research

References
Appendices
```

## 語言學 / 華語教學特化結構

```
語料庫研究：
第三章 研究語料與方法
  3.1 語料庫選擇（COCT / BCC / 其他）
  3.2 語料範圍界定（年代 / 文體 / 字數）
  3.3 檢索方式（關鍵詞設定 / 語境視窗）
  3.4 標注框架
  3.5 統計分析方法（頻率分析 / 對應分析 / 搭配分析）

教學研究（介入研究）：
第三章 研究方法
  3.1 研究設計（前後測 / 控制組 / 個案）
  3.2 教學介入設計
  3.3 評量工具（寫作評量 / 口語測驗）
  3.4 教學實施程序
  3.5 資料分析
```

## PEEL 段落結構（各章節通用）

```
P — Point（論點）
    每段第一句：本段核心主張
    例：「構式語法理論認為，語言形式與意義的對應不是任意的。」

E — Evidence（證據）
    引用支持性文獻或數據
    例：「Goldberg (1995) 指出，論元結構構式直接編碼事件框架...」

E — Elaboration（深化）
    解釋證據如何支持論點，或連結到研究問題
    例：「這意味著，學習者對構式的習得不只是記憶詞彙，而是建立...」

L — Link（連接）
    段落結尾連接到下一段或本章主題
    例：「這為本研究的分析框架提供了理論基礎，下一節將進一步說明...」
```
