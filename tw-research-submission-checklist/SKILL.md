# 學術論文投稿前檢查清單 v1.0

## 核心哲學
「**投稿前的 30 分鐘，決定你的論文命運。**
因格式問題被退稿，比因研究不足被拒審更令人沮喪。
用這份清單把關，讓審稿人專注在你的研究本身。」

> 參考設計：research-writing-skill/Red Flags system（兩階段審核機制）
> 本工具採用「合規檢查優先，品質審核其次」的雙階段方法

## Step 3：18 項投稿前檢查清單

### 第一階段：格式合規檢查（Phase 1: Compliance Check）

**A. 稿件基本格式（6 項）**

```
□ A1. 字體與字號
  標準：內文 12pt Times New Roman（英文）/ 新細明體（中文）
  行距：1.5 倍或 double space（依期刊規定）
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正  [ ] ⚠️ 需確認
  
□ A2. 頁面設定
  標準：A4 紙張，上下左右 2.5cm 或 1 inch 邊距
  頁碼：右下角或中間（依規定）
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正  [ ] ⚠️ 需確認

□ A3. 字數符合規定
  期刊字數限制：___字（投稿規定）
  目前字數：___字
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正  [ ] ⚠️ 需確認

□ A4. 摘要格式
  字數：150-250 字（英文）/ 300-500 字（中文）
  關鍵詞：5-8 個，依主題重要性排序
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正  [ ] ⚠️ 需確認

□ A5. 標題層級統一
  一級標題：置中加粗
  二級標題：靠左加粗
  三級標題：靠左加粗斜體（依 APA 7th）
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正  [ ] ⚠️ 需確認

□ A6. 匿名審稿要求
  作者資訊：已從稿件中移除（blind review）
  致謝：已移除或設為匿名（如適用）
  自我引用：已改為「（作者，年份）」
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正  [ ] ⚠️ 不適用
```

**B. 參考文獻格式（4 項）**

```
□ B1. 格式一致性
  全文使用單一格式（APA/MLA/Chicago 等）
  中英文文獻格式分別符合規範
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正

□ B2. 文內引用與書目對應
  每筆文內引用（Author, Year）均有對應書目
  每筆書目均有文內引用（無孤立書目）
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正

□ B3. DOI / URL 有效性
  所有 DOI 格式：https://doi.org/10.xxxxx
  URL 已確認可正常訪問
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正  [ ] ⚠️ 需確認

□ B4. 文獻新舊比例
  近 5 年文獻比例：≥ 40%（建議）
  最新文獻年份：___
  狀態：[ ] ✅ 通過  [ ] ⚠️ 需補充近期文獻
```

**C. 圖表規範（2 項）**

```
□ C1. 圖表格式
  圖說：圖 1. 標題（Caption 位於圖下方）
  表說：表 1. 標題（Caption 位於表上方）
  圖表解析度：≥ 300 DPI（投稿時）
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正  [ ] ⚠️ 不適用

□ C2. 圖表文內引用
  所有圖表均在文中有明確引用（如圖 1 所示）
  圖表數量符合期刊規定（一般 ≤ 8 張）
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正  [ ] ⚠️ 不適用
```

---

### 第二階段：品質與倫理審核（Phase 2: Quality & Ethics）

**D. 研究內容品質（4 項）**

```
□ D1. 研究問題清晰度
  研究問題：是否明確、具體、可測量？
  研究目的：是否與研究問題一致？
  紅旗：❌ 研究問題模糊或過於廣泛
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正

□ D2. 方法論一致性
  研究方法：是否能回答研究問題？
  樣本描述：是否完整（人數/來源/選樣標準）？
  紅旗：❌ 方法與問題不對應，❌ 樣本描述不足
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正

□ D3. 結論與數據一致性
  結論是否有數據/文獻支持？
  是否有過度推論（Over-generalization）？
  紅旗：❌ 結論超出數據支持範圍
  狀態：[ ] ✅ 通過  [ ] ❌ 需修正

□ D4. De-AI 寫作品質檢查
  是否有機械化短語？
  例：「值得注意的是」「綜上所述」「不言而喻」
  「顯著地」「從某種意義上說」「毫無疑問」
  建議：改用具體學術論述取代空泛短語
  狀態：[ ] ✅ 通過  [ ] ⚠️ 發現 ___ 處需修改
```

**E. 倫理合規（2 項）**

```
□ E1. 研究倫理聲明
  人類受試者研究：是否附 IRB 核准編號？
  知情同意：是否已取得並記錄？
  動物實驗：是否符合 IACUC 規範？
  狀態：[ ] ✅ 已附  [ ] ❌ 需補充  [ ] ⚠️ 不適用

□ E2. 利益衝突聲明
  是否有潛在利益衝突？
  資助來源：是否完整揭露？
  狀態：[ ] ✅ 已處理  [ ] ❌ 需補充  [ ] ⚠️ 無衝突
```

投稿準備度：
18/18 ✅ → 🟢 可立即投稿
15-17 ✅ → 🟡 小幅修正後投稿（1-2 天）

❌ 需修正項目清單：

   預計時間：[X 分鐘/小時]

⚠️  需確認項目清單：
1. [項目代碼]：[需向期刊確認的內容]
   確認方式：[查詢期刊官網/寄信詢問編輯]

## Step 5：期刊客製化檢查

若提供特定期刊投稿指南：

```
額外檢查項目（依期刊規定）：
□ 特定檔案格式（.docx / .pdf / LaTeX）
□ 作者貢獻聲明（Author Contribution Statement）
□ 數據可用性聲明（Data Availability Statement）
□ 補充材料（Supplementary Materials）格式
□ 結構化摘要（Structured Abstract）要求
□ 稿件分類（Article Type）選擇
```

## Step 6：投稿後追蹤建議

```
投稿後建議記錄：
📅 投稿日期：___
📋 稿件編號：___（收到確認信後填入）
⏰  預計初審結果：___ 週後
📌  如 [X] 週無消息，可寄禮貌催稿信

催稿信範例：
"Dear Editor,
I submitted a manuscript titled '[標題]' ([稿件編號]) on [日期].
I am writing to kindly inquire about the status of the review process.
Thank you for your time and consideration.
Sincerely, [作者名]"
```

## 降級方案

若使用者未提供論文全文：
- 可針對個別段落或特定項目進行局部檢查
- 提供自行核對的檢查清單 PDF 版本說明
- 建議逐項自評，最後提交確認結果
