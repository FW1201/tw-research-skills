# 紮根理論工作流程引導工具 v1.0

## 核心哲學
「**理論不是從書架上拿下來的，是從資料中長出來的。**
紮根理論最大的挑戰，不是技術而是心態：
你必須願意讓資料帶領你去你意料之外的地方。」

> 學術依據：
> - Strauss & Corbin (1990, 2015): Basics of Qualitative Research
> - Charmaz (2006): Constructing Grounded Theory
> - Glaser & Strauss (1967): The Discovery of Grounded Theory

## Step 2：紮根理論版本選擇

```
A. Strauss & Corbin 版本（傳統/結構化）
   特點：較嚴格的編碼程序，重視因果條件
   適合：較結構化的研究問題，初學者

B. Charmaz 建構主義版本（當代/彈性）
   特點：強調研究者與參與者共同建構意義
   適合：研究者反身性強，現象學傾向

C. Glaser 版本（原始經典）
   特點：最嚴格的避免預設立場
   適合：有豐富質性研究經驗者
```

## Step 3：第一層 — 開放編碼（Open Coding）

**目的**：打破資料，重新概念化

```
開放編碼原則：
□ 逐字/逐句閱讀資料
□ 問：「這段資料在說什麼概念？」
□ 給每個現象/行動/事件一個「概念標籤」
□ 不判斷，不過濾，盡量開放
□ 記錄概念定義（備忘錄）

編碼示範：
原始資料：「每次教授在課堂上叫我回答問題，我就很緊張，
          不知道說什麼好，只想逃走。」

開放編碼：
• [課堂焦慮] — 被點名時的情緒反應
• [逃避傾向] — 想要離開當下情境的衝動
• [發言不確定感] — 不知如何回應的困惑

概念備忘錄（Memo）：
「[課堂焦慮] 似乎不只是緊張，而是一種面對他人評判的存在性不安，
  可能與自我效能感有關。需要在後續訪談中追問『什麼讓你緊張？』」
```

**開放編碼輸出格式**：

```
╔══════════════════════════════════════════════╗
開放編碼記錄表
資料來源：[訪談編號/頁碼]
╠══════════════════════════════════════════════╣
編號 │ 原始資料片段 │ 概念標籤 │ 備忘錄
─────────────────────────────────────────────
001  │ [片段]       │ [標籤]   │ [備忘]
002  │ [片段]       │ [標籤]   │ [備忘]
...
╚══════════════════════════════════════════════╝

初始概念清單（出現頻率排序）：
[概念A]（出現 X 次）
[概念B]（出現 X 次）
...
```

## Step 4：第二層 — 軸心編碼（Axial Coding）

**目的**：重新整合，找出類別間的關係

**Strauss & Corbin 典範模型（Paradigm Model）**：

```
           因果條件（Causal Conditions）
                    ↓
脈絡（Context）→ 中心現象（Phenomenon） → 結果（Consequences）
                    ↓
           中介條件（Intervening Conditions）
                    ↓
                策略（Strategies）
```

**軸心編碼流程**：

```
Step 4.1：識別核心類別（Category）
將開放編碼中相似的概念群組為更高層次的類別
問：「這些概念圍繞著什麼核心現象？」

Step 4.2：建立類別屬性（Properties）
每個類別有哪些特徵/面向？
例：[課堂焦慮] 的屬性 → 強度（輕微/中度/嚴重）、
                          觸發情境（點名/報告/考試）

Step 4.3：填入典範模型
識別因果條件：是什麼導致中心現象發生？
識別脈絡條件：在什麼情境下發生？
識別策略：研究對象如何應對？
識別結果：策略帶來什麼後果？
```

**軸心編碼輸出格式**：

```
╔══════════════════════════════════════════════════════╗
軸心編碼典範模型圖
核心現象：[現象名稱]
╠══════════════════════════════════════════════════════╣
因果條件：
  • [條件一]（來自開放編碼：[概念清單]）
  • [條件二]

脈絡條件：
  • [情境描述]

中介條件（調節因素）：
  • [因素一]

策略：
  • [策略一]：[說明]
  • [策略二]：[說明]

後果：
  • [後果一]（正向/負向/中性）
  • [後果二]
╚══════════════════════════════════════════════════════╝
```

## Step 5：第三層 — 選擇編碼（Selective Coding）

**目的**：整合所有類別，形成核心類別與故事線

```
Step 5.1：識別核心類別（Core Category）
問：「哪一個類別最能統整所有其他類別？」
核心類別應該：
□ 頻繁出現在資料中
□ 與其他類別有豐富的連結
□ 能夠解釋研究現象的中心本質

Step 5.2：撰寫故事線（Storyline）
用 2-3 句話描述核心現象：
「在[脈絡]下，[研究對象]面對[核心現象]，
  透過[策略]應對，導致[後果]。
  此過程受[中介條件]影響。」

Step 5.3：確認理論密度
□ 所有主要類別都連結到核心類別？
□ 關係是否有資料支持？
□ 是否有無法解釋的反例（負面案例）？
```

## 降級方案

若研究者尚未收集足夠資料：
- 提供訪談大綱設計建議（採用紮根理論精神）
- 說明持續比較法（Constant Comparative Method）操作方式
- 建議先以 `tw-research-qualitative-analyzer` 做初步主題分析，再深化為紮根理論
