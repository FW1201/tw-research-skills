# 學術論文摘要三層精縮工具 v1.0

## 核心哲學
「**摘要是論文的第一印象，也往往是唯一被讀到的部分。**
每一個字都必須賺到它的位置。
本工具幫你把 300 字壓縮到 100 字，
同時保留所有關鍵資訊。」

> 參考設計：academic-paper-skills (lishix520) 的 abstract optimization logic
> 本工具採用「三層精縮 + 五要素結構」雙軌分析

## Step 4：三層精縮輸出

```
【原始摘要】
{使用者提供的原始摘要}
字數：[X] 字 / [X] words

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 第一層：精縮版（~150字 / ~100 words）

**精縮策略**：
- 保留所有五要素的核心句
- 刪除舉例說明（保留最重要的1個）
- 合併相似概念
- 刪除修飾性形容詞

```
【精縮版 — 150字】
{精縮後摘要}

字數：[X] 字（原文的 [N]%）
刪除內容：[說明刪除了哪些內容]
保留重點：[說明保留的核心要素]
```

---

### 第二層：極簡版（~100字 / ~70 words）

**精縮策略**：
- 每個要素只保留1句最強的句子
- 結果只保留最重要的發現
- 完全刪除研究限制與未來方向
- 強化每句話的資訊密度

```
【極簡版 — 100字】
{精縮後摘要}

字數：[X] 字（原文的 [N]%）
核心保留：背景（1句）+ 目的（1句）+ 方法（1句）+ 結果（1句）+ 貢獻（1句）
```

---

### 第三層：一句話版（≤50字 / ≤35 words）

**精縮策略**：
- 格式：「本研究[方法]研究[對象]，發現[結果]，貢獻在於[意義]。」
- 英文格式："This study [method + subject], finding [result], contributing [implication]."
- 適用：電梯簡報、社群媒體、研究計畫簡介

```
【一句話版 — 50字以內】
{一句話摘要}

字數：[X] 字
使用情境：電梯簡報 / 社群分享 / 快速介紹
```

## Step 5：關鍵詞優化

### 5.1 關鍵詞提取與評分

```
從摘要中提取關鍵詞，依以下標準評分：

評分標準：
⭐⭐⭐ 核心詞（研究主題的核心概念）
⭐⭐  方法詞（研究方法/資料類型）
⭐    背景詞（研究脈絡/領域）

建議關鍵詞清單（中文）：
1. [詞1]（⭐⭐⭐）— [說明為何重要]
2. [詞2]（⭐⭐⭐）
3. [詞3]（⭐⭐）
4. [詞4]（⭐⭐）
5. [詞5]（⭐）
6. [詞6]（⭐）
7. [詞7]（備選）
8. [詞8]（備選）

建議關鍵詞清單（英文）：
1. [English Keyword 1]
2. [English Keyword 2]
...
```

### 5.2 關鍵詞優化建議

```
優化原則：
□ 避免使用過於寬泛的詞（如：教育、語言、研究）
□ 優先使用學科領域標準術語
□ 包含研究方法關鍵詞（增加被方法論研究引用的機會）
□ 考慮目標讀者的搜尋習慣
□ 中英文關鍵詞不需一一對應（可各自優化）

⚠️  避免的關鍵詞類型：
❌ 縮寫（除非是領域標準）
❌ 作者名稱
❌ 過於新穎尚未被學界採用的術語
❌ 與摘要正文重複的短語
```

## Step 6：中英互譯優化

若需要中英文雙語摘要：

```
中文摘要 → 英文摘要 優化規則：

翻譯不是字對字，而是「概念等值」：
□ 中文四字成語 → 改用英文學術術語
□ 中文長句 → 拆成英文短句
□ 被動語態（中文常見）→ 英文主動語態
□ 「本研究」→ "This study" / "The present study"
□ 數字：中文用「百分之」，英文用「%」

英文摘要 → 中文摘要 優化規則：
□ 英文 hedge（may, might）→ 中文「可能」「初步顯示」
□ "Furthermore" → 中文用「此外」「再者」（不用「而且」）
□ 被動語態（英文常見）→ 中文主動語態
```

## Step 7：結構化摘要生成（部分期刊要求）

```
若期刊要求結構化摘要，生成以下格式：

Background: [1-2句研究背景]

Objective: [1句清楚的研究目的]

Method: [2-3句方法說明，含樣本和分析方式]

Results: [2-3句主要發現]

Conclusions: [1-2句結論和貢獻]

Keywords: [5-8個關鍵詞]
```

## 降級方案

若使用者的摘要缺少核心要素（少於 3 個）：
- 建議先使用 tw-research-proposal-diamond 或 tw-research-structure-advisor
- 使用研究問題框架補齊缺少的要素
- 再回到本工具進行精縮
