# 摘要五要素結構指南

> 設計參考：academic-paper-skills 的 abstract optimization logic
> 以及 APA 7th Edition 的摘要撰寫規範

---

## 什麼是好的學術摘要？

摘要是整篇論文的微縮版，必須回答讀者最在意的五個問題：
1. 為什麼這個研究重要？（背景）
2. 這個研究想知道什麼？（目的）
3. 怎麼做的？（方法）
4. 發現了什麼？（結果）
5. 有什麼意義？（結論/貢獻）

---

## 摘要五要素：BOMRC 框架

```
B — Background（背景）
   目的：建立研究重要性，說明研究脈絡
   字數比例：10-15%
   關鍵詞：「隨著...」「近年來...」「由於...」「在...的背景下」
   英文：As [field] grows... / Despite advances in... / Although...

O — Objective（目的）
   目的：清楚宣示研究要達成什麼
   字數比例：15-20%
   關鍵詞：「本研究旨在」「本研究目的為」「本文探討」
   英文：This study investigates... / The aim of this paper is to...
   ⚠️  注意：用動詞宣示（investigate, examine, explore），不用名詞堆砌

M — Method（方法）
   目的：說明數據來源和分析方法
   字數比例：20-25%
   關鍵詞：「以...為研究對象」「採用...方法」「運用...分析」
   英文：We analyzed... / Using [method], we examined [X participants/texts]...
   ⚠️  摘要方法段：只說「做了什麼」，不說「為什麼這樣做」

R — Results（結果）
   目的：陳述主要發現（最重要的1-3個）
   字數比例：30-35%
   關鍵詞：「研究結果顯示」「發現...」「結果表明」
   英文：The results demonstrate... / The findings reveal... / We found that...
   ⚠️  這是摘要的核心！讀者最想知道「你發現了什麼」

C — Conclusion/Contribution（結論/貢獻）
   目的：說明發現的意義和學術貢獻
   字數比例：15-20%
   關鍵詞：「本研究貢獻在於」「研究結果對...有以下啟示」
   英文：These findings contribute to... / The study suggests implications for...
   ⚠️  避免：「本研究還有一定限制，未來研究可...」（限制放在限制部分）
```

## 字數分配建議（以 300 字中文摘要為例）

```
背景（Background）：30-45 字（15%）
目的（Objective）：45-60 字（20%）
方法（Method）：60-75 字（25%）
結果（Results）：90-105 字（35%）
貢獻（Contribution）：30-45 字（15%）

總計：約 300 字
```

## 各類型論文摘要調整

### 量化研究摘要特點
- 方法段：必須提及樣本數（N=X）
- 結果段：可引用統計數字（但不宜過多）
- 範例結果語：「結果顯示，[變項A] 與 [變項B] 呈顯著正相關（r = .45, p < .001）」

### 質性研究摘要特點
- 方法段：說明質性方法類型（深度訪談/紮根理論/內容分析）
- 結果段：以主題或類別呈現（「識別出三個核心主題：...」）
- 強調：「豐富的描述性理解」而非統計數字

### 文獻評析摘要特點
- 強調系統性（「透過系統性文獻回顧...」）
- 說明篩選範圍（「分析了 X 篇 SSCI 期刊論文」）
- 結論強調對未來研究的指引

## 常見摘要錯誤

```
❌ 錯誤 1：只有背景和目的，沒有結果
   → 摘要最重要的是結果，讀者需要知道你發現了什麼

❌ 錯誤 2：結果段說「詳見第四章」
   → 摘要必須自成一體，不能引用論文章節

❌ 錯誤 3：大量使用縮寫而不解釋
   → 摘要是獨立文件，需要自行解釋縮寫

❌ 錯誤 4：把研究限制放在摘要裡
   → 摘要展示研究最佳面，限制在論文內部說明

❌ 錯誤 5：摘要和結論幾乎一模一樣
   → 摘要是整篇論文的縮寫，不只是結論的縮寫
```
