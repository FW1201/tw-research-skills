# 三階段輸出格式規格
# Dialogue Output Formats by Research Stage

---

## 格式選擇原則

- 由 SKILL.md Step 1 的「當前階段」決定使用哪種格式
- 若由其他 skill 呼叫，格式由呼叫方傳入的 stage 參數決定
- 使用者可在對話中途要求切換格式

---

## Stage A：發想期（Ideation）

### 適用情境
- 還沒有明確研究題目
- 有模糊興趣但不知道從何下手
- 想從多個方向中收斂出一個可行研究

### 核心輸出：接地氣探索地圖

```
╔═══════════════════════════════════════════════╗
📍 接地氣探索地圖
研究者：[使用者] | 主題模糊域：[輸入的興趣領域]
對話輪數：[N] 輪 | 啟用視角：[視角列表]
╠═══════════════════════════════════════════════╣

■ 經質問後存活的研究方向（依強度排序）

🥇 方向 A：[研究方向標題]
   核心問題：___
   潛在研究問題：「[具體可執行的研究問題]」
   文獻支撐狀況：有初步文獻 [1][2]
   抵抗了哪些質疑：[SKEPTIC 提的問題] → 可以這樣回應...
   本土研究可行性：高 / 中 / 低
   建議規模：行動研究（1學期）/ 碩士論文（1-2年）/ 大型計畫（2年+）

🥈 方向 B：[研究方向標題]
   ...

🥉 方向 C：[研究方向標題]
   ...

╠═══════════════════════════════════════════════╣
■ 最強方向推薦：方向 [X]
  推薦理由：[此方向最能抵抗對話中的質疑，且在台灣情境有可行性]

■ 方向 [Y] 的潛力：[雖然目前較弱，但若 ___ 條件成立，值得深探]

╠═══════════════════════════════════════════════╣
■ 下一步路徑推薦
  → 繼續：tw-research-proposal-diamond Phase 2（聚焦方向 X）
  → 驗證文獻：tw-research-lit-review（搜尋方向 X 的現有研究）
  → 釐清方法：tw-research-methodology-designer
╚═══════════════════════════════════════════════╝
```

## Stage B：文獻期（Literature）

### 適用情境
- 已完成初步文獻蒐集或聚類
- 想深化理解文獻，找到真正的研究缺口
- 準備撰寫文獻探討章節

### 核心輸出：深化缺口分析報告

```
╔═══════════════════════════════════════════════╗
📚 深化缺口分析報告
研究主題：[主題] | 文獻聚類：[N] 個群組
對話輪數：[N] 輪 | 啟用視角：[視角列表]
╠═══════════════════════════════════════════════╣

■ 各視角發現的缺口

🔴 SKEPTIC 的挑戰：
   「現有研究對 [X] 的因果聲明大多缺乏___——你的研究能彌補嗎？」
   缺口類型：方法論缺口
   文獻依據：[1][2]

🔵 METHOD 的質疑：
   「多數研究樣本集中在___，缺乏___族群的資料」
   缺口類型：對象缺口（Population Gap）
   文獻依據：[3]

🟣 LOCAL 的提醒：
   「台灣關於___的研究極少，[4] 是唯一的本土研究（___年）」
   缺口類型：情境缺口（Context Gap）
   文獻依據：[4]

🟠 BRIDGE 的啟發：
   「[其他領域] 的 [X] 概念可能重新框架你的研究問題」
   機會類型：跨領域理論整合機會

╠═══════════════════════════════════════════════╣
■ 主持人盲區注入發現
   未被任何聚類引用的重要研究：
   • [研究摘要] [5]——可能填補___缺口

╠═══════════════════════════════════════════════╣
■ 研究定位建議

「本研究填補了【___缺口】，
 在【台灣___情境】中，以【___族群】為對象，
 透過【___方法】，探討【___問題】。
 理論貢獻：___
 實務貢獻：___」

■ 下一步路徑推薦
  → 驗證引用：tw-research-citation-checker
  → 方法確認：tw-research-methodology-designer
  → 開始計畫書：tw-research-proposal-diamond Phase 3
╚═══════════════════════════════════════════════╝
```

## Stage C：寫作期（Writing）

### 適用情境
- 已有論文段落草稿
- 想確認每個論點是否有足夠的文獻支撐
- 準備投稿前的最後把關

### 核心輸出：論點接地性驗證報告

```
╔═══════════════════════════════════════════════╗
✍️ 論點接地性驗證報告
章節：[論文章節名稱] | 段落數：[N] 段
對話輪數：[N] 輪 | 檢驗論點數：[N] 個
╠═══════════════════════════════════════════════╣

■ 論點引用狀況逐一檢驗

論點 1：[論點摘要（原文前 20 字）]
  狀態：✅ 接地
  支撐來源：[1]（直接支持）、[2]（間接支持）
  說明：引用強度：強 | 來源多元性：中

論點 2：[論點摘要]
  狀態：⚠️ 待引用
  問題：有學術共識但未標注來源
  建議搜尋：「[建議關鍵詞]」
  建議引用格式：（Author, Year）指出...

論點 3：[論點摘要]
  狀態：❌ 懸空
  問題：過度強主張（「絕對」「必然」「所有研究」）但無文獻支撐
  修改選項：
  A. 弱化主張：「多數研究傾向...」而非「所有研究均...」
  B. 刪除此句：若找不到支撐文獻

論點 4：[論點摘要]
  狀態：💡 詮釋
  說明：這是研究者的詮釋，不需引用，但建議加「本研究認為...」

╠═══════════════════════════════════════════════╣
■ 全段落引用品質摘要
  接地率：[N]/[N]（[X]%）
  台灣本土引用比例：[X]%
  引用多元性評級：高 / 中 / 低
  最脆弱論點：[論點X]（建議優先處理）

╠═══════════════════════════════════════════════╣
■ SKEPTIC 的整體評語
  「[對這段論述的整體評估——什麼最強？什麼最可能被審稿人挑戰？]」

■ 修改優先序
  立即處理：論點 [列表]（❌ 懸空）
  本週內處理：論點 [列表]（⚠️ 待引用）
  確認即可：論點 [列表]（✅ 接地）

■ 下一步路徑推薦
  → 引用查核：tw-research-citation-checker
  → 段落改寫：tw-research-writing-coach（重新進行三版本改寫）
  → 全文審閱：tw-research-quality-gate
╚═══════════════════════════════════════════════╝
```
