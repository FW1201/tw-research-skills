# 引用錨定規則與格式標準
# Citation Grounding Rules for tw-research-grounded-dialogue

---

## 核心原則

**接地氣對話的「接地」指的是：每一個實質性聲明都有可追溯的來源。**

這不是要求每句話都加引用——而是要求「可驗證的知識主張」必須有來源。
觀點性陳述、問題性提問、研究者自己的詮釋，不需要引用。

---

## 什麼需要引用？

✅ 需要引用（可驗證的知識主張）：
- 「研究顯示 A 有 X% 的效果」
- 「根據 [理論]，B 會導致 C」
- 「[領域] 的主流看法是...」
- 「台灣的 [政策/現況] 顯示...」
- 「[特定研究] 發現...」

❌ 不需要引用（詮釋性/對話性內容）：
- 「這個問題值得思考」
- 「你有沒有考慮到...？」
- 「根據你的描述，我理解為...」
- 研究者本人的判斷與詮釋

---

## 行內引用格式

### 基本格式
```
根據 [1]，[具體聲明]。

[2] 的研究指出，[具體發現]。

然而，[3] 卻發現相反的結果：[對比發現]。

在台灣脈絡下，[4] 的研究（以 [研究對象] 為樣本）發現 [在地發現]。
```

### 多來源引用
```
多項研究一致發現 [共同發現] [1][2][3]。

但也有研究持不同看法 [4][5]，認為 [對比觀點]。
```

### 不確定性標注
```
根據目前可及的文獻，[聲明] [1]——但本搜尋結果有限，
建議使用 tw-research-citation-checker 進行完整驗證。
```

## 來源清單格式

每輪對話結束後，附上本輪使用的完整來源清單：

```
本輪來源：
[1] [作者姓名]（[年份]）。[標題/主題摘要]。[期刊/來源名稱]。
[2] [來源描述]（[年份]）。[內容摘要]。
[3] [機構/網站名稱]（[年份]）。[標題]。取自 [URL 或資料庫名稱]。
```

若 WebSearch 無法確認完整引用資訊：
```
[N] [來源描述]（搜尋結果，完整引用資訊待 tw-research-citation-checker 驗證）。
```

## 懸空論點標記系統（寫作期專用）

在 stage="writing" 模式下，掃描使用者提供的論文段落，
標記每個論點的引用狀態：

```
論點分類標記：
✅ [接地] — 有明確引用支撐
⚠️ [待引用] — 有來源印象但未標注，建議補充
❌ [懸空] — 無文獻支撐的強主張，需修改或刪除
💡 [詮釋] — 研究者個人詮釋，不需要引用，但需標明「本研究認為...」
```

## 搜尋策略標準

每輪對話的 WebSearch 執行規則：

1. **每輪至少 2 次搜尋**，使用不同關鍵詞確保覆蓋
2. **搜尋語設計**：
   - 中文搜尋：「[主題] [關鍵詞] 研究 Taiwan / 台灣」
   - 英文搜尋：「[topic] [keyword] empirical study OR literature review」
   - 混合：「[中文主題] [English_keyword]」
3. **搜尋失敗處理**：
   - 若 3 次嘗試均無結果 → 標注「[搜尋無結果]」
   - 降級：提出「待查問題清單」，建議使用者後續查閱

## 引用品質評級

完整輸出中附上引用品質評估：

```
本次對話引用品質：
• 總聲明數：[N]
• 有引用支撐：[N]（[X]%）
• 台灣本土來源比例：[X]%
• 引用多元性：高 / 中 / 低（是否過度依賴單一來源）

⚠️ 注意：WebSearch 結果僅供參考，正式論文引用前
   請使用 tw-research-citation-checker 進行真偽查核。
```
